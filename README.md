A Ruled Surfaces VR Project, Created by Bella Villarreal and Boston Gunderson. Presented at the 2025 JMM Undergrad Poster Sesion, and at the 5/8/2025 Grinnell College Math and Statistics Seminar. 

Usage:
To download a built (.exe) version of this project you must download the entirety of the Build folder, you are not required to have contents from any other folder. Then, to run the built project run the Ruled_Surfaces.exe.

If you wish to modify this project then you will need all other files, the build file is not required, and the Unity Editor (Version 2022.3.*). 

Please note that accredidation for the photos used in the project can be found in Assets/Prefabs/Posters/Poster Pictures.

We would like to thank previous students of Grinnell who worked on this project for creating the model of the Room we are in, and creating the smooth surface displayer, and the corresponding intersection plane.
